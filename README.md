# ふっかつのじゅもん 体験モック

社内LT「なぜドラクエ1、2は『ふっかつのじゅもん』が必要だったのか」の体験用モックです。

スマホを縦に持ったまま、じゅもんを入力して「復活」を体験できます。

## これは何か

1986年のファミコンRPGで使われていた「パスワード方式のセーブ」の仕組みを、
**ゼロから再実装したオリジナル**です。

- 冒険のデータを **112ビット（14バイト）** に詰め込む
- チェック用の **1バイト** を足して 15バイト ＝ 120ビット
- **6ビットずつ20個**に区切り、64種類のひらがなに対応させる
- そのままだと「ああああ…」と同じ文字が並ぶので、
  **ひとつ前の文字の値に +4 を足して**ずらす

「じゅもんの しくみ」メニューから、この流れを画面で追えます。
